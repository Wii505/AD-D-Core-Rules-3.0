Viewing the RTF files:
Double click on the book you want to view in the RTF folder. If the file
does not open, you will see a dialogue asking you to choose which
application you want to open the file. Choose whatever word processing
program you have on your Mac from the list. The file will open in your
word processing program.

Viewing the HTML files:
To access the individual books in html format, double click the start.htm file in the chosen 
book folder. You will have to choose whatever web browser (i.e. Netscape Navigator,
Microsoft Internet Explorer) you have on your Mac from the list. To get quicker access 
without the index, you can click on the htm file that is number **0000.htm. 


Viewing WebHelp:
The files in the WebHelp folder contain links between all twenty books. Your ability
to use these links depends on your system and browser.
